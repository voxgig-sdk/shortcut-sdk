load

GET /api/v3/search

Operation ID: search.

Authentication: API key in the header (api_token).

Parameters

| Parameter | In | Type | Required | Description | | --- | --- | --- | --- | | query | query | string | Yes | See our help center article on search operators | | page_size | query | integer (int64) | No | The number of search results to include in a page. Minimum of 1 and maximum of 250. | | detail | query | enum: full, slim | No | The amount of detail included in each result item. "full" will include all descriptions and comments and more fields on related items such as pull requests, branches and tasks. "slim" omits larger fulltext fields such as descriptions and comments and only references related items by id. The default is "full". | | next | query | string | No | The next page token. | | entity_types | query | array of enum: story, milestone, epic, iteration, objective | No | A collection of entity_types to search. Defaults to story and epic. Supports: epic, iteration, objective, story. |
